Turning pages on Windows: Bluetooth buttons, pedals, and remotes

Tapping the screen to turn a page takes a hand off your instrument. A Bluetooth page turner fixes that. Dedicated foot pedals are the usual answer, but a media remote that costs less than a set of strings works too.

The budget option: a Bluetooth media remote

I turn pages with a small 5-button Bluetooth remote sold for car steering wheels. It has buttons for play and pause, next and previous track, and volume. It comes with a strap mount meant for a steering wheel.

Standly treats the next-track and previous-track buttons as page turns with no setup. The other buttons can be assigned to other actions.

Set it up

  1. Put the remote or pedal in pairing mode. The manual explains how. Usually you hold a button until a light flashes.
  2. In Windows, open Settings → Bluetooth & devices and select Add device, then Bluetooth.
  3. Select the device from the list.
  4. Open a piece in Standly and press a button.

Most pedals and remotes identify themselves to Windows as a keyboard or as media buttons. Standly responds to both with no setup:

  • Next-track and previous-track buttons turn a full page forward and back.
  • Page Down, Page Up, and Space turn a full page.
  • Right and Left arrow keys turn half a page.

Play, pause, and volume buttons do nothing until you assign them, so a pedal cannot trigger something unexpected the first time it connects.

Change what a button does

Settings → Input bindings assigns any key or button to a viewer action. Press the button you want to change and choose the action. Changes take effect immediately.

Some useful assignments:

  • Half-page turn, so the line you are reading stays on screen while the next line appears.
  • Previous page on a second button, for repeats and D.S. jumps.

Troubleshooting

It's paired, but pages don't turn

  • Make sure a piece is open in Standly and the Standly window is in front. Buttons go to whichever app is active.
  • Find out what the button sends. Open Settings → Input bindings, start adding a binding, and press the button. If nothing appears, Windows is not receiving it.
  • Some pedals have modes that send different keys. Check the manual for a mode that sends arrow keys or Page Up and Page Down.

The volume changes when I turn a page

This needs testing. If a volume button is bound to a page turn in Standly, does Windows also change the volume? I found no code in Standly that stops the button from reaching Windows, so it probably does. If so, recommend using the track buttons for page turns. Related question to test: if Spotify or another music player is running, does the next-track button also skip its song? This section is probably the most-searched part of the page.

It stops working after a while

  • Many remotes go to sleep to save battery. Pressing a button usually wakes them, but the first press may be lost.
  • Replace or charge the battery. Low batteries cause dropped presses before the device stops completely.
  • If the connection drops often, remove the device in Windows Bluetooth settings and pair it again.
